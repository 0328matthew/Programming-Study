## 1. 1차원 배열

### 1. 배열의 개요

* **배열**은 같은 자료형의 데이터 타입이 나열된 복합 자료형이다.

### 2. 배열 속성

#### 자료형

* 배열의 자료형은 요소의 자료형을 의미한다.
* 배열 내부의 모든 요소는 같은 자료형을 가져야 한다.

#### 용적

* 배열의 용적은 보유할 수 있는 요소의 최대 수이다.
* 배열이 선언 된 이후에는 변경할 수 없다.

#### 크기

* 배열의 크기는 어떤 시점에 존재하는 요소의 수, 즉 유효한 데이터의 수이다.

### 3. 배열 생성

#### 배열 선언

* 배열 선언은 배열에 이름, 자료형, 용적을 지정하여 메모리에 할당하는 작업.
* 배열 선언은 자료형, 이름, 용적, 세미콜론으로 이루어진다.'
* 배열의 용적은 리터럴이다.
```cpp
int array[8];

const int size = 10;
double capacity[size];
```

#### 메모리 할당

* C++는 제로 인덱싱을 채택하였다.

#### 초기화

* 배열 각각의 요소는 단독적인 변수와 같다.
* 배열이 전역 영역에서 선언된 경우 모든 요소는 자료형의 기본값이 할당된다.
* 함수 내부에서 선언된 경우 쓰레기 값이 할당된다.

##### 명시적 초기화

* 중괄호 사이에 값을 지정하여 초기화 할 수 있다.
```cpp
const in CAPACITY = 8;
int scores[CAPACITY] = {87, 92, 100, 65, 70, 10, 96, 77};
```
* 객체 자료형의 배열도 위와 같은 방법으로 초기화 가능하다.
```cpp
const int CAPACITY = 4;
Circle circles[CAPACITY] = {Circle(4.0), Circle(5.0), Circle(6.0)};
```

##### 암묵적 초기화

* 용적을 지정하지 않고 배열을 선언할 수 있으나, 배열의 용적을 나타내는 상수를 생성할 수는 없다.
```cpp
int scores[] = {87, 92, 100, 65, 70, 10, 96, 77};
```
* 초기화 하는 값이 배열의 용적보다 크면 오류가 발생하지만, 작은 경우에는 배열의 나머지 값이 기본값으로 채워진다.

### 4. 배열 요소에 접근

#### 첨자 표현식

* 배열은 첨자(subscript)를 사용하여 값을 읽는다.
* 첨자 표현식에서 배열 범위를 넘어가면 쓰레기 값을 추출한다.


## 2. 배열의 연산

### 1. 변경 연산

#### 스왑

* 스왑은 배열의 두 요소를 교환하는 연산이다.
* 요소 두 개를 직접 바꾸는 게 아니라, 임시 변수를 활용해서 교환한다.

#### 요소 제거

* 지우고 싶은 요소 뒤의 요소들을 한 칸 앞으로 당긴 후 마지막 인덱스는 사용하지 못하게 한다.

#### 요소 추가

* 맨 뒤 인덱스를 한 칸 뒤로 옮긴 뒤 차례로 반복하여 삽입한다.

### 2. 배열의 함수 사용

#### 함수에 배열 전달

* 배열의 이름은 첫 번째 요소에 대한 포인터이다.
* 따라서 배열 이름을 함수로 전달하면, 주소를 함수로 전달하는 것과 같다.
* 호출된 함수에서 배열을 수정하지 않는다면 배열 앞에 `const` 한정자를 추가한다.
* 함수에서 배열 리턴을 구현하려면 유사적으로 매개변수로 배열을 전달해야 한다.
```cpp
// array를 수정할 수 없음.
void(const type array[], int size);

//array를 수정할 수 있음.
void(type array[], int size);

//array1은 수정할 수 없지만 array2는 수정 가능
void(const type array1[], type array2[], int size);
```

### 3. 병렬 배열

* 하나의 행으로 여러 값을 표현해야 할 때 병렬 배열을 사용한다.
* 병렬 배열보다는 객체 배열을 쓰는 것이 더 좋다.


## 3. 다차원 배열

### 1. 2차원 배열

* 2차원 배열은 행과 열이라는 2개의 인덱스를 사용해 요소를 저장하는 구조화된 자료형이다.

#### 선언과 초기화

* 2차원 배열의 선언도 1차원 배열의 선언 방법과 같다.
```cpp
int scores[5][3] = {{82, 65, 72},
					{73, 70, 80},
					{91, 76, 40},
					{72, 72, 68},
					{65, 90, 80}};
```

#### 연산

* 2차원 배열에서는 **배열 접기**라는 연산을 수행할 수 있다.
* 축을 기준으로 뒤집는 연산이 배열 접기이다.
