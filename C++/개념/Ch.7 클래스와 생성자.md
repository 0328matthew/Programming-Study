## 1. 클래스의 개요

### 1. 타입과 인스턴스

- 타입을 통해 인스턴스를 생성할 수 있다. 타입은 어떠한 것의 정의나 집합, 인스턴스는 개별화된 것.

#### 속성(attribute)

속성은 **인스턴스가 가지는 특징**이다.

- e.g.) 인스턴스: 학생
  - 속성: 이름, 학년, 학점 etc...

#### 행위(behavior)

인스턴스는 어떤 행위를 가진다. 여기서 **행위란, 어떤 인스턴스가 스스로 할 수 있는 작업 혹은 연산을 의미**한다.

- e.g.) 인스턴스: 학생
  - 행위: 이름, 학년 학점 등을 지정해 줄 수 있다.

### 2. 클래스와 객체

- C++에서는 Type과 Instance라는 용어를 자주 사용한다. C++는 클래스라는 구문을 사용하여 타입을 생성. 클래스를 기반으로 만든 인스턴스가 객체, 혹은 그냥 인스턴스라고 부름.
- 객체 지향 프로그래밍에서 객체의 속성과 행위는 데이터 멤버와 멤버 함수로 만든다.

#### 데이터 멤버

객체의 데이터 멤버는 속성을 표현하기 위한 변수.

- e.g.) 객체: 원
  - 데이터 멤버: 반지름

## 2. 객체 지향과 클래스

### 1. 객체 지향에 필요한 클래스의 구조

- 클래스를 기반으로 인스턴스를 만드는 것을 **인스턴스화**라고 함.
- 객체 지향 프로그래밍 언어의 코딩 순서는 클래스 정의, 멤버 함수 정의, 애플리케이션 순서.

### 2. 클래스 정의

- 새로운 타입을 만들기 위해 **클래스 정의**를 함.
- 클래스 정의는 **헤더, 본문, 세미콜론**으로 구성됨.

```cpp
class Circle {
    private:
        double radius;
    public:
        double getRadius() const;
        double getArea() const;
        double getPerimeter() const;
        void setRadius(double value);
};
```

#### 데이터 멤버 선언

클래스 정의의 첫 부분으로, 클래스의 속성을 구현하는 데 사용할 것들을 데이터 멤버로 만든다. 위 코드의 `radius`가 데이터 멤버이다.

#### 멤버 함수 선언

클래스 정의의 두 번째 부분으로, 클래스의 멤버 함수를 선언한다. 함수 내부에서 **어떤 것도 변경하지 못하게 할 때는** `const` 한정자를 붙이고, 변경을 허가할 때는 붙이지 않는다.

#### 접근 제한자

접근 제한자는 **접근 권한을 나타낼 때 사용**한다.

- **데이터 멤버**에는 일반적으로 **private**을 사용한다.
- **멤버 함수**에는 일반적으로 **public**을 사용한다.

| 접근 제한자    | 같은 클래스에서의 접근 | 서브 클래스에서의 접근 | 모든 곳으로부터의 접근 |
| --------- | :----------: | :----------: | :----------: |
| private   |      가능      |     불가능      |     불가능      |
| protected |      가능      |      가능      |     불가능      |
| public    |      가능      |      가능      |      가능      |

### 3. 멤버 함수 정의

- 멤버 함수 선언은 함수의 프로토타입을 적은 것이기에 별도로 정의한다.
- 멤버 함수의 정의는 사용자 함수 정의와 비슷하나 두 가지 차이점이 존재한다.
  1. 멤버 함수에는 한정자(**const**)가 존재한다.
  2. 멤버 함수에는 앞에 **클래스 이름**이 붙는다.
     - e.g.) `Circle::getPerimeter() const`

### 4. 애플리케이션

- main 함수 내에서 인스턴스화 하는 것으로, 인스턴스화 하는 방법은 `Circle circle1;`이다.
- 처음 선언한 뒤의 데이터 멤버에는 쓰레기 값이 들어가 있으므로, 초기화를 해 줘야 한다.
- 인스턴스화 하고 변수를 초기화 했다면 `circle1.getRadius()` 처럼 멤버 함수를 호출하여 연산할 수 있다.

## 3. 생성자와 소멸자

### 1. 객체의 생성과 소멸

- 객체는 **생성자, constructor**라고 하는 멤버 함수가 호출될 때 생성된다.
- 객체가 더 이상 필요 없는 경우, **소멸자, destructor**라고 하는 멤버 함수를 호출하여 객체를 정리한다.

### 2. 생성자

- 생성자의 두 가지 특징
  1. 리턴값이 없다.
  2. 이름이 클래스의 이름과 같다.
- 생성자는 매개변수가 있는 생성자, 기본 생성자, 복사 생성자라는 3가지로 구별한다.

#### 생성자 선언

생성자는 클래스의 멤버 함수이므로 클래스 정의에서 선언해야 한다. 생성자는 리턴값이 없고, 이름이 클래스 이름과 동일해야 한다. 또한, `const` 한정자를 붙일 수 없다.

##### 매개변수가 있는 생성자, parameter constructor

데이터 멤버를 지정된 값으로 초기화 하기 위해 매개변수가 있는 생성자를 사용한다. 매개변수가 있는 생성자는 오버로드 가능하므로 시그니처가 다르면서 여러 개의 매개변수가 있는 생성자를 가질 수 있다.

##### 기본 생성자, default constructor

기본 생성자는 매개변수가 없는 생성자를 의미한다. 모든 데이터 멤버를 리터럴 값으로 초기화할 때 사용한다. 오버로드 할 수 없다.

##### 복사 생성자, copy constructor

객체의 데이터 멤버를 이전에 만들었던 다른 객체와 동일한 값으로 초기화 할 때 사용한다. 복사 생성자는 매개변수로 자신과 같은 객체의 참조를 하나 받는다. 매개변수 앞에 `const` 한정자를 붙이는데, **이는 원본 객체를 변경하지 못하게 하기 위해 붙이는 것이다.**

```cpp
class Circle {
    ...
    public:
        Circle(double radius);        // 매개변수가 있는 생성자
        Circle();                     // 기본 생성자
        Circle(const Circle& circle); // 복사 생성자
};
```

```cpp
Circle::Circle(double rds)
: radius(rds) {             // 초기화 리스트
                            // 문장
}

Circle::Circle()
: radius(1.0) {             // 초기화 리스트(생략하면 쓰레기 값 할당됨.)
                            // 문장
}

Circle::Circle(const Circle& cr)
: radius(cr.radius) {       // 초기화 리스트
                            // 문장
}
```

### 3. 소멸자

- 소멸자의 두 가지 특징
  1. 소멸자의 이름은 클래스 이름 앞에 `~`이 붙은 형태이다.
  2. 소멸자는 리턴값을 가질 수 없다.
- 소멸자는 별도의 매개변수를 가질 수 없어 오버로드 할 수 없고, 자동으로 호출된다.

#### 소멸자 선언

```cpp
class Circle {
    ...
    public:
        ...
        ~Circle(); // 소멸자
};
```

#### 소멸자 정의

소멸자도 다른 멤버 함수처럼 정의하나, `~`를 붙임에 유의한다. 소멸자는 `public`을 사용한다.

```cpp
Circle::~Circle() {
    // 문장
}
```

### 4. 생성자와 소멸자의 호출

생성자를 호출하면 객체가 생성되고 생성자 내부에서 데이터 멤버를 초기화한다. 객체가 제거될 때는 소멸자가 호출되고, 데이터 멤버를 정리한다. 객체가 제거되고 나면 객체가 있던 메모리 영역이 해제된다.

## 4. 인스턴스 멤버

### 1. 인스턴스 데이터 멤버

- 인스턴스 데이터 멤버는 인스턴스의 속성을 정의한다.
- 각각의 객체의 데이터 멤버는 캡슐화 되기 때문에, 인스턴스끼리 서로 접근할 수 없다.

#### 인스턴스 데이터 멤버의 접근 제한자

- 인스턴스 데이터 멤버는 일반적으로 `private`으로 설정하는 것이 좋다.

### 2. 인스턴스 멤버 함수

- 인스턴스 멤버 함수는 인스턴스의 행위를 뜻한다.
- 인스턴스 데이터 멤버는 모든 객체가 개별적으로 갖지만, 멤버 함수는 모든 인스턴스가 공유한다.

#### 인스턴스 멤버 함수의 접근 제한자

- 일반적으로 `public` 제한자를 붙인다. 클래스 외부에서 접근하기 위함이다.

#### 인스턴스 멤버 함수 선택자

- 객체 지향 프로그래밍의 애플리케이션 부분에서는 인스턴스를 생성하고, 인스턴스가 인스턴스 멤버 함수를 호출하게 해야 한다.
- 이를 위해 C++는 멤버 선택 연산자 두 개를 제공한다.

| 이름       | 연산자  |    표현식     |   결합방향   |
| -------- | :--: | :---------: | :------: |
| 멤버 선택    | `.`  |  `객체.멤버`   | 왼쪽 → 오른쪽 |
| 간접 멤버 선택 | `->` | `포인터->멤버` | 왼쪽 → 오른쪽 |

#### 명시적인 포인터 사용

- `this` 포인터를 사용하지 않은 경우, 변수 이름 충돌을 피하기 위해 데이터 멤버와 매개변수를 다른 이름으로 사용해야 한다.
- 하지만 `this` 포인터를 사용하면 데이터 멤버와 매개변수를 같은 이름으로 사용할 수 있다.

#### 접근자 멤버 함수

- 접근자 멤버 함수는 호스트 객체의 정보를 추출할 때 사용하는 함수이다.
- read-only 함수이다.
- 함수 헤더 끝에 `const` 한정자를 추가해 주는 것이 좋다.
- 접근자 함수는 일반적으로 매개변수 목록을 갖지 않는다.

#### 설정자 멤버 함수

- 객체는 매개변수가 있는 생성자에서 초기화한다. 이후 데이터 멤버를 변경해야 할 때, 설정자 멤버 함수를 사용한다.
- 호스트 객체의 상태를 변경하므로 `const` 한정자를 붙이면 안 된다.
- 매개변수가 없어도 데이터 멤버의 값을 변경한다면 설정자 함수이다.

### 3. 클래스 불변 속성

- 클래스 불변 속성은 클래스의 데이터 멤버 일부 또는 전체에 적용해야 하는 하나 이상의 조건을 의미한다.
- e.g.) 원에 대한 클래스에서, 데이터 멤버로 음수가 입력되었을 때 `assert(false)`로 프로그램을 중단.

## 5. 정적 멤버

### 1. 정적 데이터 멤버

- 정적 데이터 멤버는 클래스 또는 모든 인스턴스에 포함되는 멤버이다.

#### 정적 데이터 멤버 선언

- 정적 데이터 멤버는 클래스 정의에서 선언한다.
- `static` 키워드를 붙여야 한다.

```cpp
class Rectangle {
    private:
        ...
        static int count; // 정적 데이터 멤버
    public:
        ...
};
```

#### 정적 데이터 멤버 초기화

- 정적 데이터 멤버는 인스턴스에 속하는 것이 아니므로 생성자에서 초기화할 수 없다.
- 정적 데이터 멤버는 클래스 정의 후에 초기화해야 한다. (프로그램 전역에서 초기화한다.)
- 값을 초기화 할 때는 클래스 이름과 `::` 을 사용하여 클래스에 속함을 명시해야 한다.
- 하지만 `static` 한정자를 추가하면 안 된다. 이미 클래스 정의에서 선언했기 때문이다.
```cpp
int Rectangle::count = 0; // 정적 데이터 멤버 초기화
```

### 2. 정적 멤버 함수

#### 정적 멤버 함수 선언

- 정적 멤버 함수도 클래스에 속하는데, `static` 한정자를 앞에 붙여준다.
```cpp
class Rectangle {
    private:
        ...
        static int count;
    public:
        static int getCount(); // 정적 멤버 함수
        ...
};
```

#### 정적 멤버 함수 정의

- 정적 멤버 함수 또한 클래스 외부에서 정의한다. 인스턴스 멤버 함수와의 판별법은 선언을 확인하는 것이다.
- 정적 멤버 함수는 호스트 객체가 없으므로 `const` 한정자를 사용할 수 없다.

#### 정적 멤버 함수 호출

- 정적 멤버 함수는 인스턴스 혹은 클래스를 통해서 호출할 수 있다.
- 인스턴스 멤버 함수를 호출할 때와 같은 구문을 사용한다.
- 정적 멤버 함수에는 호스트 객체가 없으므로 정적 멤버 함수 내부에서 인스턴스 데이터 멤버에 접근할 수 없다.
- 인스턴스 멤버 함수에서는 정적 데이터 멤버에 접근할 수 있으나 일반적으로 그러하지 않는다.

## 6. 객체 지향 프로그래밍

### 1. 파일 분할

#### 인터페이스 파일

- 인터페이스 파일은 클래스 정의가 포함된 파일이다.
- 일반적으로 `.h` 확장자를 붙인다.

#### 구현 파일

- 구현 파일은 멤버 함수 정의가 포함된 파일이다.
- 모든 멤버 함수의 선언을 입력한다.
- 일반적으로 `.cpp` 확장자를 붙인다.

#### 애플리케이션 파일

- 객체를 인스턴스화하고 객체를 활용하는 `main()` 함수가 들어간 파일이다.
- 반드시 `.cpp` 확장자를 사용한다.

### 2. 분할 컴파일

#### 분할 컴파일 과정

1. 인터페이스 파일에 클래스 정의(데이터 멤버&멤버 함수 선언)만 작성한다.

2. 구현 파일에서 `include` 지시문으로 인터페이스 파일을 읽어 들인다. 아래처럼 컴파일한다. 컴파일이 성공하면 `.o` 객체 파일이 만들어진다.

   ```bash
   c++ -c circle.cpp
   ```

3. 애플리케이션 파일에서는 `main` 함수를 작성한다. 아래와 같이 컴파일 한다.
   컴파일에 성공하면 `.o` 파일이 만들어진다.

   ```bash
   c++ -c app.cpp
   ```

4. 만들어진 두 개의 `.o` 파일을 다음과 같이 `.exe` 파일로 만든다.

   ```bash
   c++ -o application circle.o app.o
   ```
