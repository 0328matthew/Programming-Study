## 1. 자료형과 문자열

### 1. 자료형

* **자료형**이란 자료의 형식.
* `type()` 함수로 확인할 수 있다.

### 2. 문자열 만들기

* **문자열**은 글자들이 나열된 것. 영어로는 String이라고 한다.
* Python의 경우 큰따옴표(`"`)와 작은따옴표(`'`) 둘 다 사용 가능.
* **이스케이프 문자**를 사용하여 문자열 안에서 큰따옴표와 작은따옴표 출력 가능.

### 3. 문자열 연산자

#### 문자열 연결 연산자 `+`

* 문자열은 `+` 연산자로 문자열 연결 연산을 적용할 수 있다.

```python
>>> print("string" + "String")
stringString
```

* 다만, `+`의 경우 문자열과 문자열의 결합에서만 사용이 가능하다. 즉, 숫자와 결합은 불가하다.

#### 문자열 반복 연산자 `*`

* 문자열을 숫자와 `*` 연산자로 연결하면 문자열을 반복할 수 있다.

```python
>>> print("안녕하세요" * 3)
안녕하세요안녕하세요안녕하세요
>>> print(3 * "안녕하세요")
안녕하세요안녕하세요안녕하세요
```

#### 문자 선택 연산자(인덱싱) `[]`

* 파이썬의 경우 제로 인덱싱을 채택하였다.

```python
>>> print("안녕하세요"[0])
안
```

* 대괄호 안에 `:` 을 통해 인덱싱 범위를 지정할 수 있다. 끝 숫자는 포함하지 않는다.

```python
>>> print("안녕하세요"[1:4])
녕하세
```

* 위와 같이 `:` 을 쓸 경우, 두 숫자 중 하나를 생략하여 그 이후 전체, 혹은 이전 전체를 인덱싱 할 수 있다.

### 4. 문자열의 길이 구하기

* 문자열의 길이를 구할 때는 `len()` 함수를 사용한다.

```python
>>> print(len("안녕하세요"))
5
```


## 2. 숫자

### 1. 숫자의 종류

* 기본적으로 Python은 두 개의 숫자 자료형을 제공한다.
* `int`의 경우 정수 자료형이다.
* `float`의 경우 부동소수점(실수) 자료형이다.

### 2. 숫자 연산자

#### 사칙연산자

* 사칙연산자에는 더하기, 빼기, 곱하기, 나누기가 존재하며 각각 `+`, `-`, `*`, `/`를 입력하여 사용한다.
* C++와 다른 점: `/`는 피연산자가 정수여도 항상 `float`를 반환한다.

```python
>>> print(4 / 2)
2.0
```

#### 정수 나누기 연산자 `//`

* 나눗셈에서 버림을 원할 경우 `//`을 사용함으로써 구현할 수 있다.

```python
>>> print(3 / 2)
1.5
>>> print(3 // 2)
1
```

#### 나머지 연산자 `%`

* 나눗셈의 나머지를 구한다.

```python
>>> print(7 % 3)
1
```

* C++와 다른 점: 피연산자가 음수일 때 결과의 부호가 다르다. Python은 나누는 수의 부호를 따른다.

```python
>>> print(-7 % 3)
2
```


## 3. 변수와 입력

### 1. 변수 선언과 사용

#### 1. 변수 선언법

* C++과 크게 다르지 않으나, 자료형을 명시하지 않아도 된다.

```python
Variable = value
```

### 2. 복합 대입 연산자

* C++와 크게 다르지 않으나, 제곱에 대한 연산자가 추가되었다.

| 연산자 이름 | 설명                |
| :-----: | :---------------- |
|  `+=`   | 숫자 덧셈 후 대입        |
|  `-=`   | 숫자 뺄셈 후 대입        |
|  `*=`   | 숫자 곱셈 후 대입        |
|  `/=`   | 숫자 나눗셈 후 대입       |
|  `%=`   | 숫자의 나머지를 구한 후 대입  |
|  `**=`  | 숫자 제곱 후 대입        |

* 문자열도 마찬가지로 복합 대입 연산자를 쓸 수 있다. 단, 문자열 연산자가 있는 `+=`(연결)와 `*=`(반복)만 가능하다.

### 3. 사용자 입력 함수 `input()`

#### 1. `input()` 함수로 입력받기

* `input()` 함수에서 괄호 안을 **프롬프트 문자열**이라고 하며, 입력 받을 내용을 출력한다.

```python
>>> input("인사말을 입력해주세요: ")
```

* 이 때 사용자가 입력한 내용은 `input()` 함수의 결과이다.
* 이 결과는 변수에 대입하여 사용할 수 있다.

#### 2. `input()` 함수의 입력 자료형

* `input()` 함수로 내용을 입력 받았을 때, 그 자료형은 모두 `str`형이다.

### 4. 문자열과 숫자의 상호변환(Casting)

#### 문자열을 숫자로 변환하기

* `int()` 함수로 문자열을 `int`형으로 바꿀 수 있다.
* `float()` 함수로 문자열을 `float`형으로 바꿀 수 있다.

#### 숫자를 문자열로 변환하기

* `str()` 함수를 통해 숫자를 문자열로 변환할 수 있다.


## 4. 숫자와 문자열의 다양한 기능

### 1. 문자열의 `format()` 함수

* 문자열 안의 중괄호(`{}`)가 `format()`의 매개변수로 차례대로 대치된다. 이 과정에서 숫자를 넣어도 결과는 문자열이 된다.

```python
>>> print("{} {}".format(10, 20))
10 20
```

### 2. `format()` 함수의 다양한 기능

#### 1. 정수 출력의 형태

* `"{:d}".format()`의 경우 매개변수로 정수만을 받음을 명시한다.
* `"{:5d}".format()`의 경우 **전체 폭을 그 숫자만큼(이 경우 5칸) 확보**하고 오른쪽 정렬하여 출력한다. 남는 자리는 공백이 된다.
* `"{:05d}".format()`의 경우 남는 자리를 공백 대신 `0`으로 채운다.
* `"{:+d}".format()`의 경우 양수에도 `+` 기호를 명시하여 출력한다.
* `"{: d}".format()`처럼 부호 자리에 공백을 두면, 양수는 부호 자리에 공백이 오고 음수는 `-`가 온다.
* 부호 앞에 `=`을 붙이면 부호를 출력문의 맨 앞에 고정하고, 그 뒤의 남는 자리를 채운다.

```python
>>> print("{:+d}".format(52))
+52
>>> print("{:+d}".format(-52))
-52
>>> print("{: d}".format(52))
 52
>>> print("{:=+5d}".format(52))
+  52
```

#### 2. 부동소수점 출력의 형태

* 부동소수점의 경우도 정수 출력과 비슷하다.
* `d` 대신에 `f`를 중괄호 안에 입력하여 부동소수점을 출력할 수 있다.
* 부동소수점의 경우 다만 소수점 아래 자릿수를 명시할 수 있다.

```python
>>> print("{:.2f}".format(52.273))
52.27
```

* 이 때, 자동으로 반올림 하여 계산한다.
* 의미없는 `0`을 생략하고 싶을 때는 `{:g}`를 사용한다.

### 3. `upper(), lower()`

* `upper()` 함수는 문자열의 알파벳을 모두 대문자로 치환한 새로운 문자열을 반환한다.
* `lower()` 함수는 문자열의 알파벳을 모두 소문자로 치환한 새로운 문자열을 반환한다.

### 4. `strip(), lstrip(), rstrip()`

* `strip(), lstrip(), rstrip()` 모두 문자열의 공백을 제거한다.
    * `strip()`의 경우 문자열의 양 옆 공백을 제거한다.
    * `lstrip()`의 경우 문자열 왼쪽 공백을 제거한다.
    * `rstrip()`의 경우 문자열 오른쪽 공백을 제거한다.

### 5. `isXX()`

* `is`로 시작하는 함수들의 경우 해당 문자열이 특정 조건을 만족하는지 여부에 대해 판별한다.

|      함수 이름       | 역할                              |
| :--------------: | :------------------------------ |
|   `isalnum()`    | 문자열이 알파벳 또는 숫자로만 구성되어 있는지 확인한다. |
|   `isalpha()`    | 문자열이 알파벳으로만 구성되어 있는지 확인한다.      |
| `isidentifier()` | 문자열이 식별자로 사용할 수 있는지 확인한다.       |
|  `isdecimal()`   | 문자열이 정수 형태인지 확인한다.              |
|   `isdigit()`    | 문자열이 숫자로 인식될 수 있는지 확인한다.        |
|   `isspace()`    | 문자열이 공백으로만 구성되어 있는지 확인한다.       |
|   `islower()`    | 문자열이 소문자로만 구성되어 있는지 확인한다.       |
|   `isupper()`    | 문자열이 대문자로만 구성되어 있는지 확인한다.       |

### 6. `find(), rfind()`

* `find(), rfind()`는 문자열 내부에서 특정 문자가 어디에 위치하는지 알아낼 때 사용한다.
    * `find()`의 경우 문자열의 왼쪽부터 찾아서 최초 발견 위치를 반환한다.
    * `rfind()`의 경우 문자열의 오른쪽부터 찾아서 최초 발견 위치를 반환한다.
* 어느 쪽이든 반환하는 인덱스는 **왼쪽 기준**이다. 찾지 못하면 `-1`을 반환한다.

### 7. `in` 연산자

* 문자열 내부에서 특정 문자열이 존재하는지 확인할 때 `in` 연산자를 사용한다.

```python
>>> print("안녕" in "안녕하세요")
True
```

### 8. `split()`

* 문자열을 특정한 문자로 자를 때 `split()`을 사용한다.

```python
>>> a = "10 20 30 40 50".split(" ")
>>> print(a)
['10', '20', '30', '40', '50']
```

* 위 예제와 같이 반환할 때 **리스트** 형태로 반환된다.
