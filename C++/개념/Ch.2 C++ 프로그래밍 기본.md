## 4. 자료형
### 4.1 정수 자료형
#### 1. 정수 자료형의 종류

| 자료형       | 부호    | 범위                     |
| --------- | ----- | ---------------------- |
| short int | 부호 있음 | -32768~32767           |
|           | 부호 없음 | 0~65536                |
| int       | 부호 있음 | -2147483648~2147483647 |
|           | 부호 없음 | 0~4294967295           |
| long int  | 부호 있음 | -2147483648~2147483647 |
|           | 부호 없음 | 0~4294967295           |
### 4.2 문자 자료형
#### 1. char 자료형
```
char first;
char second;
```
#### 2. 이스케이프 문자의 종류

| 문자  | 설명                     |
| --- | ---------------------- |
| \n  | 줄바꿈 문자                 |
| \t  | 탭 문자                   |
| \b  | 백스페이스                  |
| \r  | 캐리지 리턴(커서의 위치를 앞으로 이동) |
| \f  | 폼 피드(다음 페이지로 넘긱기)      |
| \\' | 작은 따옴표                 |
| \\" | 큰 따옴표                  |
| \\\ | 역 슬래시                  |
### 4.4 부동 소수점 자료형

| 자료형         | 접미사 | 예시       |
| ----------- | --- | -------- |
| float       | F   | 12.23F   |
| double      |     | 14525.36 |
| long double | L   | 2456.23L |
### 4.5 문자열 자료형
#### 1. 문자열 자료형을 쓰는 법
string 헤더를 불러와야 한다.
```
#include <string>

string name;
```
